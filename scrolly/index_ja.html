「世界で一番働き者の国は?」— 答えはたぶん想像どおり。ほとんど誰も知らないのは、その称号の代金が何で支払われたのかです。33カ国・数千人が1日を分単位で記録した「生活時間の日記」を開いてみましょう。あなたの24時間も、途中でランキングに参加できます。

次に、眠っていない順に並べ替える。

下のスイッチで並べ替えてみてください。ほとんどの国は順位が大きく入れ替わります — よく働く国が、よく眠っていたりする。1カ国だけ、どちらでも頂点に居座る国があります。スライダーで自分の時間を入れると「あなた」も参戦します。

1日あたりの分数(15〜64歳・全人口・週7日平均)。仕事には休日や働いていない人も含めて平均するため、フルタイム勤務の体感より小さく出ます。出典: OECD Time Use Database。

反論 · 平均は嘘をつく

「日本人はもう、アメリカ人ほど働いていない」

…公式統計は、そう言います。年間労働時間は日本 1,654時間、アメリカ 1,789時間(2023年) — 日本のほうが135時間も短い。ここまでの話は幻だったのでしょうか。いいえ。平均という数字が、二つの日本を混ぜて薄めているのです。短時間で働く人が増えるほど平均は下がり、働きすぎの中核は見えなくなる。

では、混ぜるのをやめましょう。週49時間以上働く人の割合を数え直すと — 順位は反転します。

男性は5人に1人が週49時間以上。女性はアメリカをすら下回る。この極端な偏りが家庭の中で何を意味するのか — 第三幕で、もう一度この非対称に出会うことになります。

出典・注記

出典: ILO(JILPT データブック国際労働比較2025・第6-3表)。就業者のうち週49時間以上働く人の割合。2023年にデータのある22カ国。年間労働時間は Penn World Table(Our World in Data 経由, 2023年)——生活時間調査(OECD)とは別系列。

幕間 · 両極対決

世界一眠る国と、世界一眠らない国。

睡眠553分の南アフリカと、444分の日本。差は109分。その109分がどの項目から捻出されているのか、両国の24時間の帳簿を突き合わせます。対戦カードは両側とも自由に変更できます。

終幕 · 49日分の請求書

世界一の労働時間は、世界最短の睡眠で支払われていた。

働く時間は世界一。通勤と身支度は世界3位。そのぶん睡眠・家事・友人との時間は世界最下位圏で、不足の負担は家庭の中で均等ではありませんでした。日本の睡眠不足を1年分、束にするとこうなります。

処方箋 · 時間は増やせない。質は取り戻せる。

削られた夜は、量ではなく“質”で取り戻す。

仕事も家事も、削れない可処分時間は決まっている。だから狙うのは睡眠の「量」ではなく「質」。同じ7時間でも、深く眠れれば回復は変わる。睡眠研究が繰り返し支持してきた、確実な3つのレバーがあります。就寝の目標時刻を決めるだけで、今夜からの逆算が出ます。

出典・注記

出典: 睡眠研究で広く支持される知見(体内時計と光の同調 / 就寝前入浴と深部体温: Haghayegh ら 2019 系統的メタ分析 / カフェインの睡眠影響: Drake ら 2013)。時刻は逆算の目安で、最適値には個人差があります。

付記 · データについて

これは、同じ年の写真ではありません。

生活時間調査は、数千〜数万人に1日の行動を10分刻みの日記で記録してもらう、とても重い調査です。どの国も実施は10〜15年に1回ほどで、撮影のタイミングもバラバラ。この作品の33カ国は、1998〜2019年のどこかで撮られた「各国の最新の1枚」を並べたアルバムです。点に触れると国名と調査年が出ます。

出典・注記

日本は2016年(総務省「社会生活基本調査」ベース)。日記式の測定のため、年間総労働時間などの労働統計とは定義が異なります。

データ: OECD Time Use Database / OECD Gender Data Portal「Time use across the world」(調査年1998–2019、15–64歳)。日記式の測定であり、年間総労働時間の労働統計とは定義が異なります。
